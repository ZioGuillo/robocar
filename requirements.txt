# GPIO backend — board-specific, installed automatically by scripts/install.sh
# based on /proc/device-tree/model. Import errors are caught gracefully on
# non-Pi/Jetson systems (app/hardware/gpio_compat.py), so nothing here is a
# hard requirement:
#   Raspberry Pi 3/4        → RPi.GPIO
#   Raspberry Pi 5          → rpi-lgpio  (drop-in RPi.GPIO replacement for the RP1 chip)
#   Jetson Nano / Jetson    → Jetson.GPIO
#
# picamera2 handles CSI cameras via libcamera on a Raspberry Pi — system package:
#   sudo apt install -y python3-picamera2
# On boards without picamera2 (Jetson Nano, or a USB webcam on a Pi), camera_driver
# falls back to any V4L2 camera via OpenCV:
#   pip install opencv-python-headless
# tflite-runtime — no PyPI wheels for Python 3.13+ on ARM; install manually if needed:
#   pip install tflite-runtime  (Python <=3.11 only)
#   sudo apt install python3-tflite-runtime  (if available in apt)
# Without it, ml_driver.available = False and detection is silently disabled.
